# ParkEasy AI: portfolio screenshots

These were captured on 2026-10-29 in a headless Linux sandbox, using Playwright Chromium at 1440×900.
`gate_server.py` ran **unmodified** from this repo. The only things replaced at runtime were the
pieces of hardware and the assets that the sandbox doesn't have. A launcher script did the patching;
nothing in the repo was edited:

| Missing in sandbox | Stand-in used |
|---|---|
| USB cameras (`cv2.VideoCapture(index, CAP_DSHOW)`) | a looping **synthetic test video** (a drawn car with the fake plate `B 1234 TES`, labelled "SYNTHETIC TEST FEED" in the frame) |
| ESP32 on `COM3` | a Linux **pty**, driven by a small script that sends real protocol lines (`[HCSR04_MASUK] 7.9`, `SLOT:A1:DITEMPATI`, …) |
| Supabase | a dummy unreachable URL (`supabase.invalid`), so DB calls fail and the log records them as failures. The real project was never contacted. |
| YOLOv8 `best.pt` (gitignored, so not in the repo) | a placeholder that returns **no detections** |
| PaddleOCR models | a placeholder that returns nothing (the sandbox's network policy blocks the model download hosts) |

**This means none of these images show real model output.** YOLO and PaddleOCR never ran.

## Files

| File | What it shows | Real or not |
|---|---|---|
| `01-fastapi-docs-swagger.png` | FastAPI `/docs` (Swagger UI) listing all endpoints: `/stream/masuk`, `/stream/keluar`, `/manual/open`, `/system/reset`, `/status` | Real UI generated by the running server* |
| `02-fastapi-docs-status-live-call.png` | Swagger "Try it out" on `GET /status`, with the live response `serial/cam_masuk/cam_keluar: true` | Real server response (serial = pty, cams = test video) |
| `03-fastapi-docs-manual-open-live-call.png` | Swagger "Try it out" on `POST /manual/open` (emergency gate open for `B1234TES`), with the live 200 response and the plate normalised to `B 1234 TES` | Real server response |
| `04-fastapi-redoc.png` | FastAPI `/redoc` | Real UI generated by the running server* |
| `05-mjpeg-stream-masuk.png`, `05-mjpeg-stream-keluar.png` | The `/stream/masuk` and `/stream/keluar` MJPEG endpoints open in Chromium | Real streaming endpoint. The **frames are synthetic test video**, not a camera. |
| `06-status-endpoint-json.png` | Raw `GET /status` JSON | Real server response |
| `07-terminal-gate-server-log.png` | Server stdout during a run: boot, serial connect, ESP32 sensor handshakes, VL53L1X slot events (the DB updates fail because Supabase is a dummy), HC-SR04 vehicle trigger, then gate-in / gate-out detection, the `ANIM_KAMERA` / `TIDAK_TERDETEKSI` UART replies, then emergency open | The log text is real. It was rendered to an image with a monospace HTML page. "Tidak Terdeteksi Plat Nomor" appears because the YOLO stand-in returns nothing. |
| `08-terminal-esp32-uart-traffic.png` | Both directions of serial traffic on the pty (`ESP32 ->` is simulated input, `ESP32 <-` is the commands the server really sent) | The server→ESP32 lines are real. The ESP32→server lines are scripted. |
| `09-terminal-websocket-broadcast.png` | Frames that a client recorded from `ws://…/ws` during the same run: `log`, `hcsr04`, and `sensors` (sensor frames condensed to slot and servo state) | Real WebSocket broadcast |

\* FastAPI loads Swagger UI and ReDoc from cdn.jsdelivr.net, which the sandbox blocks. Playwright served
the same `swagger-ui-dist@5` and `redoc@2` files instead, taken from the npm registry.

## Not captured

- **Annotated detection image (bbox + OCR text):** `best.pt` isn't in the repo, and the PaddleOCR model
  hosts (huggingface.co, paddle-model-ecology.bj.bcebos.com, modelscope.cn, aistudio.baidu.com) are
  blocked in this sandbox. To get this image, run `anpr_service.run_anpr_on_image()` locally with the weights.
- **Dashboard / slot-monitoring / logs pages:** this repo serves no HTML pages (there are no templates and no static folder).
  Those screens are in the separate ParkEasy Front-End repo, which uses this server's `/ws` and `/stream/*`.
